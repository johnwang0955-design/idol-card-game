# VRoid Studio 製作指南（之後升級用）

> 目前遊戲裡的 3 位偶像是用 pixiv 授權樣本模型「程式改造」而成，**你現在不需要做任何事**。
> 這份指南是給之後想把偶像換成「自己捏的臉與髮型」時用。照著做，交出檔案後我們的程式就能直接接上。

## 1. 安裝
- 官方免費下載：https://vroid.com/studio （Windows / macOS；Steam 版也可以，會自動更新）
- 建議版本：**v2.14.0 以上**（2026/6 版，有繁體中文介面）

## 2. 三位偶像身形必須「完全相同」（最重要）
所有服裝是共用同一副骨架，身形不同衣服就會穿模。
1. 先做第一位（建議凜音），在「身體」分頁調好身高/頭身/腿長後，**之後不要再動任何身體滑桿**。
2. 第二、三位：在第一位的檔案上「另存新檔」再改臉和頭髮，**不要從新範本開始**。
3. 或：身體分頁 → 右上「⋯」→ 儲存為預設（preset），另兩位套用同一個 preset。

## 3. 成熟優雅的造型建議（對照 2D 立繪）
| 偶像 | 髮色 | 眼睛 | 個性/重點 |
|---|---|---|---|
| 凜音 | 深海軍藍 `#1a2350`（亮部 `#5d6fb8`） | 紫 `#7b4fd0` | 酷炫、長直髮、月亮髮飾 |
| 晴夏 | 奶茶粉棕 `#b5857a` | 琥珀 `#c48a2a` | 優雅溫柔、長捲髮、左眼下淚痣、珍珠髮夾 |
| 莉亞 | 珊瑚橘 `#f0743a` | 水藍綠 `#1fbfbd` | 活潑流行、側馬尾、星星髮飾、淡雀斑 |
- 眼睛：縮小 5–10%、眼角略上揚、虹膜高光少一點 → 比較成熟。
- 臉：下巴稍長、臉頰稍窄；眉毛細一點。
- 頭身：7 頭身左右，腿長 +5%。

## 4. 服裝（4 品牌 × 8 件 = 32 件）
品牌：午夜鋒芒 / 玫瑰絲絨 / 糖霜緞帶 / 彩虹汽水；每品牌 a、b 兩套，各含上衣・下身・鞋子・配件。
- 最省事的交法：**用同一位偶像（同身形）穿上每一套，各匯出一個 VRM** → 最少 **8 個服裝檔**（4 品牌 × a/b）。
- 再加 **3 個偶像本體檔**（穿最簡單的內搭/練習服即可）→ 總共 **11 個 VRM**。
- 程式會依材質名稱把上衣/下身/鞋子拆成獨立零件，所以請**不要勾「材質合併/減少材質」**。
- 配件（耳環、包包）VRoid 不好做，可以先不做，我們用程式生成。

## 5. 匯出設定（手機效能）
- 匯出 → VRM 1.0
- 多邊形減少：頭髮 / 身體適度減少（目標每個檔 < 4 萬三角面）
- 貼圖：解析度 **2048**；勾「刪除透明網格」
- **不要勾**「減少材質數」（會把衣服合在一起，無法拆零件）
- 骨骼：保留預設（彈簧骨不要刪，裙擺/頭髮才會晃）

## 6. 檔名規則
```
idol_rinne.vrm   idol_haruka.vrm   idol_ria.vrm
outfit_mid_a.vrm outfit_mid_b.vrm  outfit_ros_a.vrm outfit_ros_b.vrm
outfit_sug_a.vrm outfit_sug_b.vrm  outfit_pop_a.vrm outfit_pop_b.vrm
```

## 7. 怎麼交檔
- 小於聊天附件上限：直接在對話裡附上 .vrm。
- 太大：壓成 zip 放 Google Drive（設「知道連結者可檢視」）或 GitHub Release，貼連結給我。
